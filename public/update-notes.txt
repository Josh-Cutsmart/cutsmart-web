Version: v0.4.4

whatsNew: [
<u><b>Sidebar</b></u>
<ul>
<li>The left sidebar can now be dragged to resize between its full width and a compact icon-only width, and remembers whichever you left it at</li>
<li>Added a <b>Lock Sidebar Resizing</b> option in User Settings to freeze it at its current width and disable the drag handle</li>
</ul>

<u><b>Cutlist</b></u>
<ul>
<li>Closing Initial Measure or the Production Cutlist now shows a summary popup, covering:
  <ul>
  <li>Part counts by type, broken down by room when a project has more than one</li>
  <li>How many parts have been added or removed since you first opened it this session</li>
  <li>Sheet counts by board/sheet size — Production's version reads directly off the same numbers shown in Board Settings' own <b>Sheets</b> column, so the two always match</li>
  </ul>
</li>
<li>The Production summary also compares against Initial Measure and calls out anything <b>Missing From Production</b></li>
</ul>

<u><b>Quote & Specifications</b></u>
<ul>
<li>The formatting toolbar is now hidden once a Quote or Specifications version has been sent to the client, since it's read-only at that point</li>
<li>Added dependency <b>Rules</b> to groups in both the Quote and Specifications template builders — set a group to automatically turn on/off based on whether a Product is selected on the project</li>
</ul>

<u><b>Leads</b></u>
<ul>
<li>Custom fields a client filled in on a lead form now carry through when that lead becomes a project, shown in a new <b>From Lead</b> card on the project's Overview tab</li>
</ul>

<u><b>Dashboard & Leads</b></u>
<ul>
<li>Fixed a bug where board columns could lock up partway through scrolling and become difficult or impossible to scroll back up</li>
<li>Column title text is now bigger and easier to read</li>
<li>A column title's underline (on hover) now matches its text colour instead of looking mismatched on darker status colours</li>
</ul>

<u><b>Mobile</b></u>
<ul>
<li>Popups no longer get covered by the on-screen keyboard — they now shift up to stay visible above it</li>
</ul>

<u><b>App-Wide</b></u>
<ul>
<li>Fixed the text cursor being invisible in some fields in dark mode</li>
</ul>
]
